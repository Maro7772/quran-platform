## 🌟 المميزات الرئيسية (Key Features)

### 👩‍🏫 1. لوحة تحكم المعلمة / المشرفة (Teacher Dashboard)
* **إدارة الحلقات المباشرة:** جدولة الحلقات ومواعيدها، ربط روابط Zoom / Google Meet وملاحظات الورد اليومي.
* **رصد الحضور والغياب الذكي:** تسجيل حالة الطالبات بنقرة واحدة (حاضرة 🌸 / غائبة ⚠️).
* **إدارة طلبات الانضمام:** تفعيل واعتماد حسابات الطالبات الجدد مع التحقق الأمني.
* **تخصيص تسجيلات الفيديو:** المعلمة تملك تحكماً كاملاً في تحديد الطالبات اللاتي يظهر لهن كل فيديو، مع فلاتر سريعة بنقرة واحدة:
  * `🌸 الحاضرات فقط` (للتثبيت والمراجعة)
  * `⚠️ الغائبات فقط` (لتعويض الغياب ومتابعة الورد)
  * `طالبات محددات بالاسم` مع بحث مباشر

### 🧕 2. لوحة تحكم الطالبة (Student Dashboard)
* **عرض الحلقات القادمة:** متابعة موعد الحلقة القادمة والعد التنازلي مع رابط الحضور المباشر.
* **مكتبة التسجيلات المخصصة:** مشاهدة التسجيلات المتاحة لحساب الطالبة فقط والمصنفة بوضوح (`مخصص لكِ من المعلمة 🌸` / `تعويض غياب` / `مراجعة وتثبيت`).
* **عداد الصلاحية التلقائي:** شارة ذكية توضح الأيام والساعات المتبقية لانتهاء مهلة الـ ٧ أيام لكل تسجيل.
* **سجل الحضور والغياب:** تتبع تاريخ الحضور ونسب الالتزام بالحلقات.

## 🎬 مشغل الفيديو وحماية الخصوصية (Secure Video Player)

تم بناء مشغل فيديو قرآني مخصص **معرب 100%** ومصمم لتوفير أعلى درجات الأمان والخصوصية:

* 🔒 **العلامة المائية الديناميكية المتحركة (Dynamic Anti-Leak Watermark):** تتحرك باستمرار فوق الفيديو حاملةً اسم الطالبة ورقم هاتفها والوقت لمنع أي تسريب للتسجيلات.
* 🛡️ **درع الحماية ضد لقطات الشاشة (Anti-Screenshot Protection):** إيقاف وتشويش الشاشة فوراً عند محاولة الضغط على `PrintScreen` أو أدوات الفحص أو تصوير الشاشة.
* 🎛️ **أدوات تحكم مرنة واحترافية:**
  * تقديم وتأخير سريع (`١٠ ثوانٍ`).
  * تحكم دقيق ومنفصل بمستوى الصوت مع مؤشر لوني ذهبي.
  * خيارات سرعة التلاوة المعربة (`٠.٧٥×` ، `١× عادي` ، `١.٢٥×` ، `١.٥×` ، `٢×`).
  * زر تغيير السرعة بلمسة واحدة المخصص لشاشات الهواتف المحمولة (`1-Tap Speed Cycle`).
  * دعم كامل للشاشات الكاملة (Fullscreen) على الهواتف والحواسيب.

## 🛠️ التقنيات المستخدمة (Tech Stack)

### Frontend (الواجهة الأمامية)
* **React 19 & TypeScript:** لأعلى درجات الأداء والأمان البرمجي.
* **Vite:** محرك بناء فائق السرعة.
* **TanStack Router:** نظام توجيه حديث مع Type-Safe Routing.
* **TanStack Query (React Query):** إدارة البيانات والتخزين المؤقت وحالات الخادم.
* **TailwindCSS & Vanilla CSS Tokens:** تصميم عصري بألوان قرآنية هادئة (الأخضر الزيتي، الذهبي، والترابي الدافئ).
* **Lucide React Icons:** حزمة أيقونات عصرية وخفيفة.

### Backend (الخلفية وقاعدة البيانات)
* **Node.js & Express.js:** بيئة خادم قوية ومستقرة.
* **PostgreSQL (Neon Serverless DB):** قاعدة بيانات علائقية سحابية موثوقة وسريعة.
* **Prisma ORM:** إدارة المخططات وهجرة البيانات (Migrations).
* **JWT & HttpOnly Cookies:** نظام مصادقة آمن متعدد الأدوار (RBAC).
* **Zod:** التحقق الصارم من صحة البيانات والمدخلات.
* **Multer:** رفع ومعالجة ملفات الفيديو والوسائط.

## 🚀 التشغيل المحلي (Local Setup)

### 1. استنساخ المستودع:
```bash
git clone https://github.com/Maro7772/quran-platform.git
cd quran-platform
```

### 2. تشغيل السيرفر (Backend):
```bash
cd api
npm install
npx prisma generate
npm run dev
```

### 3. تشغيل الواجهة (Frontend):
في نافذة موجه أوامر جديدة:
```bash
cd web
npm install
npm run dev
```
افتح المتصفح على: `http://localhost:5173`

## 🌐 النشر والرفع لايف (Deployment)

* **الواجهة الأمامية:** جاهزة ومُهيأة للنشر الفوري على منصة **Vercel** من خلال مجلد `web/` مع متغير البيئة `VITE_API_URL`.
* **الخلفية:** جاهزة للنشر على **Render** أو **Railway** من خلال مجلد `api/` مع المتغيرات البيئية (`DATABASE_URL`, `JWT_SECRET`, `PORT`).
